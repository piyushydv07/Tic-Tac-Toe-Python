# Tic-Tac-Toe Game

A two-player Tic-Tac-Toe game built using Python, NumPy, and Streamlit.

## Features

- Interactive 3×3 game board
- Two-player gameplay (X and O)
- Win and draw detection
- Turn tracking
- New Game button to reset the board
- Warning when a player selects an occupied cell

## Technologies Used

- Python
- NumPy
- Streamlit

## Concepts Practiced

- Functions
- Conditional statements
- Loops
- NumPy arrays
- Game logic
- Streamlit session state
- Interactive UI elements

## How to Run

Install the required libraries:

`pip install streamlit numpy`

Run the application:

`streamlit run app.py`
